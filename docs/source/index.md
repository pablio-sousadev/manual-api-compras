# Manual da API de Compras

**Guia de Consulta e Integração à API de Compras Governamentais do PNCP**

---

O **PNCP** disponibiliza uma API REST pública para consulta de dados de contratações públicas federais. Este manual orienta desenvolvedores, integradores de sistemas e gestores sobre como utilizar os endpoints disponíveis, seus parâmetros e dados de retorno.
